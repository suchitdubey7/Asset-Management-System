# AMIS Frontend Dashboard

A modern React-based dashboard for the Asset Management Intelligence System (AMIS), tailored for Indian markets.

## Features

- **Overview Tab**: Key metrics, performance chart, and sector exposure pie chart.
- **Portfolio Tab**: Detailed holdings table with symbols, shares, prices, and weights.
- **Risk Tab**: Risk metrics like Sharpe ratio, max drawdown, volatility, and sector exposure bar chart.
- **Alerts Tab**: System alerts and macro risk factors.

## Tech Stack

- **React**: Frontend framework
- **Tailwind CSS**: Utility-first CSS for styling
- **Recharts**: Charting library for interactive visualizations
- **Axios**: HTTP client (for future API integrations)

All tools are free and open-source.

## Setup

1. Ensure Node.js is installed.
2. Navigate to the frontend directory: `cd frontend`
3. Install dependencies: `npm install`
4. Start the development server: `npm start`
5. The dashboard will load data from `/reports/amis_results.json`

## Data Source

The dashboard fetches data from a local JSON file (`public/reports/amis_results.json`), which is generated by the backend AMIS system.
